## Sobre o Projeto

O **Desafio da Esteira** é um jogo educativo interativo desenvolvido para ensinar e fixar o funcionamento do algoritmo de ordenação **Bubble Sort**. 

Em cada fase, o jogador se depara com uma esteira contendo caixas numeradas fora de ordem. O grande desafio é ordená-las em **ordem crescente** utilizando **estritamente trocas entre elementos vizinhos**, simulando exatamente a lógica de varredura do Bubble Sort. 

### Principais Funcionalidades
* **Lógica Pura:** Implementação do Bubble Sort em JavaScript puro.
* **Cálculo de Mínimo Ideal:** O jogo calcula automaticamente o número ótimo de trocas necessárias para ordenar a lista (baseado no conceito de inversões).
* **5 Fases Progressivas:** Níveis de dificuldade crescentes para testar a agilidade e o raciocínio.
* **Simulação do Robô:** Um modo de demonstração automática que mostra o passo a passo de como o algoritmo resolve a mesma fase, utilizando animações visuais (comparações e trocas).
* **Relatório de Desempenho:** Ao concluir cada fase, um relatório exibe o número de acertos e o excesso de trocas (erros) cometidas em relação ao mínimo ideal.
* **Log em Tempo Real:** Histórico completo de todas as ações executadas na esteira.
