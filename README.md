## Sobre 
**Desafio da Esteira** é um jogo educativo que ensina, de forma interativa, como funciona o algoritmo **Bubble Sort**.
Em cada fase, uma esteira de caixas numeradas aparece fora de ordem. O objetivo é ordená-las em ordem crescente, trocando apenas caixas vizinhas, exatamente como o Bubble Sort faz. Ao final, o jogo mostra quantas trocas você fez em comparação com o mínimo ideal do algoritmo.
